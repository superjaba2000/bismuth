# Руководство пользователя

## Запуск

Для запуска из исходников установите Node.js 22 или новее, установите зависимости командой `npm install` и запустите:

```bash
npm start
```

Команда запускает dev-режим и читает настройки из `src/defaults/`. Инструкции по пользовательской конфигурации находятся в разделе [настройки](../configuration/index.md).

## Управление

По умолчанию:

- **Tab** — перейти к следующей вкладке (Welcome пропускается после старта).
- **Space** — play/pause.
- **.** — следующий трек.
- **,** — предыдущий трек.
- **Ctrl+C** — выход.
- **Левый клик по прогресс-бару** — перемотка к выбранной позиции.

Клавиши управления можно изменить в `config.yml`.

Во вкладке Files перемещайтесь по файловому менеджеру средствами терминального интерфейса и нажмите Enter, чтобы открыть файл. Выбранные треки отображаются в списке воспроизведения.

Вкладка Config пока не предоставляет настроек. Скачивание музыки через Yandex Music не реализовано.

## Аудио и требования

Поддерживаются форматы, декодируемые FFmpeg, в том числе MP3, OGG и WAV. Для чтения метаданных требуется `ffprobe`; для декодирования используется системный `ffmpeg` или пакет `ffmpeg-static`.

Если исполняемые файлы находятся вне `PATH`, задайте `FFPROBE_PATH` и `FFMPEG_PATH`.

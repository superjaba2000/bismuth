# Архитектура Bismuth

## Основные части

- `src/app.js` создаёт и запускает приложение.
- `src/core/` содержит `Application`, состояние приложения, загрузчик конфигурации, управление окружением и горячими клавишами.
- `src/audio/` отвечает за декодирование и воспроизведение аудио.
- `src/tracks/` содержит модели трека и плейлиста.
- `src/ui/` строит терминальный интерфейс на `reblessed`: управление вкладками и темами, плеер и UI-компоненты.
- `src/defaults/` содержит стандартный `config.yml` и тему `basic`.

## Запуск приложения

`Application.init()` инициализирует окружение, читает YAML-конфигурацию, задаёт начальное состояние, подключает горячие клавиши, аудиосистему и UI. `NODE_ENV=development` направляет приложение к ресурсам `src/defaults/`; остальные значения используют пользовательский каталог конфигурации. В production-режиме стандартные настройки копируются туда при первом запуске.

## Воспроизведение

Пользователь выбирает аудиофайл во вкладке Files. Аудиосистема получает метаданные с помощью `ffprobe`, декодирует аудио через FFmpeg и выводит звук через Web Audio API и `speaker`. Команды интерфейса передаются приложению событиями; состояние приложения обновляет плеер и список воспроизведения.

## Конфигурация тем

`ConfigManager` читает `config.yml` и добавляет отсутствующие значения по умолчанию. `ThemeManager` загружает YAML-описания и компоненты тем, объединяет `based-on` с родительской темой и разрешает ссылки между компонентами. Подробнее — в разделе [настройки](../configuration/index.md).

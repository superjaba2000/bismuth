# Настройка

Приложение использует YAML-файлы. В dev-режиме (`npm start` и `npm run debug`) они читаются из `src/defaults/`. В production-режиме файлы находятся в пользовательском каталоге конфигурации:

- Linux: `~/.config/bismuth/` или `$XDG_CONFIG_HOME/bismuth/`
- macOS: `~/Library/Application Support/bismuth/`
- Windows: `%APPDATA%\bismuth\`

При первом production-запуске Bismuth копирует туда `config.yml` и стандартные темы. Существующие файлы не перезаписываются. Чтобы сбросить настройки, вручную отредактируйте или удалите соответствующий файл.

## config.yml

В `config.yml` задаются используемая тема, начальная вкладка и клавиши управления. Пример:

```yaml
theme: basic
show-welcome-screen: true

binds:
  change-tab:
    - tab
  play-pause:
    - space
  next-track:
    - "."
  previous-track:
    - ","
```

`show-welcome-screen` определяет, открывать ли приветственную вкладку при запуске. `binds` задаёт клавиши для переключения вкладки, play/pause и перехода к следующему или предыдущему треку. Клавиши `.` и `,` взяты в кавычки, чтобы YAML прочитал их как строки.

Приложение объединяет пользовательские настройки с настройками по умолчанию. После изменения файла перезапустите приложение.

## Темы

Темы хранятся в `themes/<name>/`: `theme.yml` описывает тему, а YAML-файлы в `components/` задают стили компонентов. Унаследовать стандартную тему можно так:

```yaml
theme:
  name: my-theme
  description: My custom theme
based-on: basic
```

Компоненты пользовательской темы могут содержать только значения, которые нужно изменить. Стандартную тему `basic` не редактируйте: создайте отдельную папку темы и переопределите в ней нужные параметры. Для выбора темы укажите её имя в `config.yml`:

```yaml
theme: my-theme
```

Темы загружаются при запуске; после изменений перезапустите приложение.

# Модули Bismuth

## Основные модули

### src/index.js
**Основной файл приложения**
- Инициализация blessed экрана
- Обработка глобальных горячих клавиш (q/C-c для выхода, r для перезагрузки UI, a для перезагрузки аудио)
- Запуск инициализации аудио и UI систем

### src/logger.js
**Система логирования**
- Использует Winston для логирования
- Создает директорию logs автоматически
- Логирует в файл с временными метками

### src/ui.js
**Управление пользовательским интерфейсом**
- Загружает конфигурацию из JSON5 файлов
- Инициализирует компоненты UI
- Отображает сообщения пользователю

### src/util.js
**Утилиты**
- `clamp()`: ограничение значения в диапазоне

### src/filemanager.js
**Модифицированный файловый менеджер**
- Основано на blessed filemanager
- Добавлено выделение аудио-файлов (♫)
- Требует ручной замены в reblessed

## Аудио модули (src/audio/)

### AudioSystem.js
**Основная аудио система**
- Управление Web Audio API контекстом
- Загрузка и воспроизведение треков
- Управление громкостью и позицией

### AudioExplorer.js
**Получение информации о треке**
- Получение метаданных через ffprobe
- Извлечение title, artist, duration

### AudioDecoder.js
**Декодирование аудио**
- Использует FFmpeg для конвертации в PCM
- Создает AudioBuffer для Web Audio API

### AudioLoader.js
**Загрузка трека**
- Проверяет выбранный файл
- Получает метаданные и декодирует аудио через AudioExplorer и AudioDecoder

## UI компоненты (src/ui/)

### player-box.js
**Компонент плеера**
- Кнопки управления (play/pause, prev/next)
- Прогресс-бар и время воспроизведения
- Отображение информации о треке

### tab-files.js
**Вкладка файлов**
- Файловый менеджер для выбора треков
- Загрузка выбранных файлов

### tab-header.js
**Заголовок вкладок**
- Переключение между вкладками (Files, Yandex, Config)
- Анимация показа/скрытия заголовков вкладок
